# 千岛湖 · 骑行手记

根据家庭千岛湖骑行影像整理的静态博客页面，含竖屏短片。

## 预览

```bash
cd qiandao-blog
python3 -m http.server 4173
```

浏览器打开 `http://localhost:4173`。

## 内容结构

1. **启程** — 桥上戴头盔出发
2. **湖路** — 千岛湖骑行节奏
3. **惊喜** — 银杏落叶与大黄蜂雕像
4. **短片** — `video/qiandao-cycling-highlight.mp4`（约 24 秒竖屏）

## 短片说明

由出行照片剪辑：标题卡 → 桥上出发 → 戴头盔 → 湖风同行 → 路边惊喜 → 银杏黄昏 → 收尾卡，含缓推镜头与淡入淡出。
